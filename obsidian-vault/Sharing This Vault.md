# Sharing this vault (GitHub, free)

Back to [[FTC Home]]

The vault lives in the team repo, in the `obsidian-vault/` folder:
https://github.com/gopsmonkey/ftc_retroraiders_biobuzz

Anyone with access to the repo can read and edit it. No paid Obsidian plan needed.

## First-time setup (each teammate)
1. Install [Obsidian](https://obsidian.md) (free) and [GitHub Desktop](https://desktop.github.com) (or plain git).
2. Clone `gopsmonkey/ftc_retroraiders_biobuzz`.
3. In Obsidian: **Open folder as vault** → pick the `obsidian-vault` folder inside the clone.

## Contributing
- **Before you edit:** Pull (GitHub Desktop: *Fetch origin* → *Pull*).
- **After you edit:** Commit with a short message, then Push.
- Optional: the free community plugin **Obsidian Git** (Settings → Community plugins → Browse → "Git") can pull on open and auto-commit/push every few minutes.
- Two people editing the same note at once can cause a merge conflict. Keep edits to your own notes when possible, and pull often.
- Don't commit `.obsidian/workspace.json` (it's per-person and already ignored).

## Where things go
- `Shooter/`: shooter issues, evidence, fixes
- `Robot/`: hardware and tuning
- `Software/`: repo, branches, code notes
