# Research sources

Back to [[BIOBUZZ Full Research Context]] · [[FTC Home]]

## Data files (this folder)
- `ftcscout-top-opr-2026-11-20.tsv`: top 193 teams worldwide by OPR, as rank, number, name, OPR.
- `ftcscout-top60-breakdown-2026-11-20.json`: top OPR records broken down per team (auto, TIPs, FLOWER, HIVE, W-L).
- `ftcscout-query.sh`: helper for the FTCScout GraphQL API (`api.ftcscout.org/graphql`, season 2026). Run `. ./ftcscout-query.sh`, then `q '<graphql query>'`. Rankings move every week, so re-pull before scouting.

## Official documents
- Competition Manual (TU10 used): https://ftc-resources.firstinspires.org/ftc/game/manual
- Field resources (CAD, Event Field Setup Guide; HIVE ballast calibration is in §12.3): https://ftc.game/field
